# IELTS Vocabulary Learning - HTML Version

基于《Check Your English Vocabulary for IELTS》的专业词汇学习系统，包含精美的 HTML 页面。

## 📚 项目结构

```
html/
├── index.html                      # 首页
├── chapters/                       # 章节内容
│   ├── how-something-works.html    # How Something Works
│   └── reason-result.html          # Reason & Result
├── exercises/                      # 练习
│   └── reason-result-exercises.html # 练习集
├── tests/                          # 测试
│   └── reason-result-test.html      # 严格测试
└── assets/                         # 静态资源
    └── css/
        └── style.css               # 样式表
```

## 🎯 功能特点

- 📖 **精美设计**：现代化 UI 设计，响应式布局
- 🔍 **清晰分类**：章节、练习、测试分类清晰
- 📱 **移动友好**：支持各种设备访问
- 🎨 **专业配色**：使用渐变、阴影、圆角等现代设计元素

## 🚀 快速开始

直接在浏览器中打开 `index.html` 文件即可开始学习。

## 📝 源文件

Markdown 源文件位于项目根目录：
- `How_Something_Works_词汇笔记.md`
- `Reason_Result_ApplicationSupport_定制版.md`
- `Reason_Result_练习集.md`
- `Reason_Result_严格测试.md`

## 📚 学习内容

### 第一章：How Something Works
描述设备/系统工作原理的词汇，适用于：
- 雅思听力（Listening）
- 雅思写作 Task 1（Writing Part 1）

### 第二章：Reason & Result
表达"原因、目的、结果"的词汇，已定制为 Application Support 场景：
- 口语沟通
- 会议讨论
- 跨团队协作
- 故障通报
