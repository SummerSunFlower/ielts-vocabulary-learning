Part A：词汇填空（30分）

说明：从括号中选择最合适的词汇填空，每题 2 分

词汇库： increase, rise, go up, peak at, reach a peak of, decrease, decline, drop, fall, go down, fluctuate, remain constant, remain steady, dramatically, sharply, steadily, gradually, slightly, upward trend, downward trend, adjust, alter, deteriorate, switch, vary, reduce, replace, transform, improve, expand, adapt, cut

A.1 趋势描述词（Changes 1，8题，每题2分）

1. After the hotfix, error rate __________ from 8% to 1.2% within an hour.
[dropped / rose / peaked]

2. API latency __________ steadily from 90ms to 140ms during the traffic surge.
[remained / rose / fluctuated]

3. Traffic __________ at 14:00 and then began to taper off.
[peaked / fell / remained steady]

4. CPU utilization __________ between 40% and 70% throughout the night.
[fluctuated / increased / dropped]

5. Uptime __________ steady at 99.95% for the whole quarter.
[remained / decreased / peaked]

6. The number of open incidents __________ a peak of 47 during the outage.
[reached / fell / fluctuated]

7. There is a clear __________ in ticket volume since we shipped the fix.
[downward trend / upward trend / fluctuation]

8. Throughput dropped __________ when the rate limiter kicked in.
[sharply / gradually / slightly]

A.2 状态变化动词（Changes 2，7题，每题2分）

9. We __________ to a different monitoring tool after the old one missed alerts.
[switched / remained / peaked]

10. The legacy billing system was __________ by a cloud-native platform.
[replaced / fluctuated / rose]

11. Service stability began to __________ after the bad deploy.
[deteriorate / improve / remain steady]

12. To meet the deadline, we __________ two low-priority features from the release.
[cut / expanded / peaked]

13. We __________ the retry timeout to avoid cascading failures.
[adjusted / reached / dropped]

14. The migration __________ the way we ship software to production.
[transformed / fluctuated / remained]

15. Customer satisfaction __________ a lot by region and by channel.
[varies / peaks / drops]

Part B：句子改写（20分）

说明：用更精确/正式的词汇改写，每题 4 分

改写：The number of errors __________ after the release.

17. 原句：Latency went down a lot when we cached the responses.
改写：Latency __________ when we cached the responses.

18. 原句：The load went up and down all night.
改写：The load __________ all night.

19. 原句：We changed the old server to a new one.
改写：We __________ the old server with a new one.

改写：The process __________ after the retro actions.

Part C：情境对话（30分）

说明：填入适当的词汇完成对话，每空 3 分

C.1 故障指标通报（15分）

场景：在 Slack 向 Dev 团队通报错误率飙升

Support: Hey @dev-team, error rate on checkout __________ (21) from 1% to 8% in the last 20 minutes. This is __________ (22) about 3,000 orders.

Dev Lead: What changed?

Support: It started right after the 14:00 deploy, and latency also __________ (23) sharply.

Dev Lead: Probably the new payment call. Let's rollback.

Support: Agreed. Once we roll back, I expect error rate to __________ (24) back to normal.

C.2 进度趋势汇报（15分）

场景：向 Sponsor 汇报进度偏差扩大

PM: The schedule variance has __________ (25) from 5 to 12 days, because of the vendor API delay.

Sponsor: Can we recover?

PM: We __________ (26) two backend engineers from the reporting stream to protect the critical path. Velocity should __________ (27) gradually next sprint.

Sponsor: And the risk rating?

PM: It __________ (28) from high to medium after the dry-run passed.
