# IELTS Vocabulary Learning

基于《Check Your English Vocabulary for IELTS》的词汇学习系统，包含精美的 HTML 页面版本。

## 🌐 在线访问

**HTML 精美版本：** 直接访问 [`html/`](./html/) 目录，在浏览器中打开 `index.html` 即可。

或者 **[点击这里](./html/index.html)** 直接访问学习首页。

---

## 📚 项目结构

```
.
├── 📂 html/                          # HTML 精美版本（推荐）
│   ├── index.html                     # 首页
│   ├── chapters/                      # 章节内容
│   ├── exercises/                     # 练习
│   ├── tests/                         # 测试
│   └── assets/css/style.css          # 样式表
│
└── 📄 Markdown 源文件（根目录）
    ├── How_Something_Works_词汇笔记.md
    ├── Reason_Result_ApplicationSupport_定制版.md
    ├── Reason_Result_练习集.md
    └── Reason_Result_严格测试.md
```

## 🎯 HTML 版本特点

- 📖 **精美设计**：现代化 UI，渐变背景，响应式布局
- 🔍 **清晰导航**：首页 → 章节 → 练习 → 测试，结构清晰
- 📱 **移动友好**：支持手机、平板、电脑访问
- 🎨 **专业排版**：对话场景、词汇卡片、练习交互

## 🚀 快速开始

### 方法 1：直接访问（推荐）
在浏览器中打开 `html/index.html` 即可开始学习。

### 方法 2：本地服务器（可选）
```bash
cd html/
python3 -m http.server 8000
```
然后访问 `http://localhost:8000`

## 📝 学习内容

### 第一章：How Something Works
描述设备/系统工作原理的词汇
- 适用：雅思听力、写作 Task 1

### 第二章：Reason & Result  
表达"原因、目的、结果"的词汇（已定制为 Application Support 场景）
- 适用：口语沟通、会议讨论、跨团队协作
